02 / A QUADRATIC BLOCK IS NOT THE WHOLE PROBLEM
Solve a block. Audit the residual.
With the opposite factors fixed, jointly fit this entity's bias and factor row by (AᵀA + λI)θ = Aᵀt. λ penalizes every bias and factor once in the global sum-squared objective, not once per observation. All block objectives decrease within numerical tolerance.
Normal matrix, right-hand side, current point and gradient
Numerical stationarity is separate from global optimality. A supplied 2×2 interaction matrix has exactly zero gradient at all-zero factors and objective 4, while a feasible nonzero factorization has objective 0.4. Stopping on a zero gradient alone cannot prove a global minimum.
