MIDYA / RATINGLABCONDITIONAL RESPONSE / NOT CAUSAL INFLUENCE

ONE OBSERVATION / FINITE RESPONSE / FROZEN OPPOSITE FACTORS

A block is
not a retrain.

Change or remove one training rating. Re-solve exactly one conditional ridge problem. Keep everything else frozen, and make that limit impossible to miss.

This is not full-model leave-one-out cross-validation or data unlearning. The frozen opposite factors and training mean were learned with the original observation. This calculation does not remove that information. It does not estimate causal influence, recommendation quality, uncertainty or a person's preferences.

01 / THREE STATES, NOT ONE AMBIGUOUS DIFFERENCE

Saved. Re-solved. Changed.

The saved user block need not still solve its own normal equations after the last item pass. We first re-solve the unmodified block with current opposite-side parameters fixed. The edit or deletion is measured against that conditional baseline, never silently against the saved point.

These are unbounded raw rating scores. No [0,2] clipping is applied to the calculation. A continuous edit is a hypothetical number, not a new real observation. No model or source file is changed.

02 / RANK-ONE ALGEBRA, NOT AN ATTRIBUTION LABEL

Residual times response direction.

H = AᵀA + λI, θ = H⁻¹Aᵀt, z = H⁻¹a, h = aᵀz. Editing the selected target by δ gives θ + δz. Deleting it gives θ − z(tᵢ − aᵀθ)/(1 − h). Bias and factors are regularized together. The training mean and every opposite-side bias/factor stay fixed.

Conditional ridge leverage h
Deletion denominator 1 − h
Query-score derivative for a target edit

Positive λ makes the full and deleted conditional systems positive definite, even if the selected row is the only observation. In exact arithmetic 0 ≤ h < 1 and 1 − h ≥ λ/(λ + ‖a‖²). Readouts use floating-point arithmetic, not interval or rational certificates. A small normal residual is not a bound on full-ALS retraining or generalization.

03 / HOLD THE QUERY UNIVERSE FIXED
One block. Every opposite index.
No new model selection or test result is introduced. The original eight factor candidates, stronger independently selected bias control, train/validation/test split and every original fit remain unchanged.


04 / REPRODUCE A NARROW CLAIM WELL
Delete locally. Check independently.
Sixty additional tiny rational design systems check finite edits and deletions against independent exact Gaussian elimination. All 2,784 selected-model/bias-control training-row deletions on both sides are checked against fresh conditional solves. Scalar JavaScript checks 576 native references, including vectors, saved-to-baseline movement, leverage and query derivatives. This is established ridge and Sherman-Morrison algebra, an original educational implementation.
