02 / THE SMALL SYSTEM THAT COUPLES ROWS

One Schur system. Shared responses.

H = AᵀA + λI, θ = H⁻¹Aᵀt. For selected design rows B, Z = H⁻¹Bᵀ, K = BZ and S = I − K. Edits give θ + Zδ. Joint deletion gives θ − ZS⁻¹(tₛ − Bθ). The update uses linear solves, not an explicitly formed normal-matrix inverse. The condition diagnostic solves against identity columns.

Positive ridge makes S positive definite in exact arithmetic. A conservative lower eigenvalue bound is λ/(λ + ‖A‖²F). This is a mathematical bound, not a floating-point certificate. Deletions refuse lost numerical positivity, condition estimate above 10¹², or excessive scaled normal residual. No jitter or silent numerical repair is applied. Native Python reports eigenvalues and infinity-norm condition; browser code uses an independent Cholesky implementation and infinity-norm condition estimate.
