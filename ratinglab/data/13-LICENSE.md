# Original UCI ratings data

Only `rating_final.csv` from Restaurant & Consumer Data (2011) is retained.

Creators: Rafael Ponce Medellín and Juan Gabriel González Serna. UCI Machine Learning Repository, DOI 10.24432/C5DP41.

Source: https://archive.ics.uci.edu/dataset/232/restaurant+consumer+data

The original source file is unchanged, including CRLF line endings. SHA256 fc994ea4e872365fc63e7f0bc970b36f86edeb4e80218d6a674a3d0e51181901. Only overall ratings are used; no profiles, locations or restaurant metadata are bundled. Its auxiliary food/service targets are retained only as original source bytes, not modeled. Browser and reports use a deterministic sorted-identifier mapping to zero-based indices and export only overall ratings.
